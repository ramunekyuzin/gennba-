原価区分 振り分け

品名を入れると 資材 / 労務 / 外注 / 設備 に自動判定。1行に1品名で複数OK。
業者からの請求書モード ON: 人工・人夫・手間などの人件系 → 外注 / OFF: → 労務(自社)
判定ルールを追加・確認
辞書にない言葉が出てきたらここに追加。追加したルールはこのスマホ/ブラウザ内に保存される。
判定は「マイルール → 標準辞書」の順で、長いキーワードほど優先。
判定の考え方(メモ)
① モノを買った → 資材(残るモノ・消耗品)
② 人の手間 → 自社作業員なら労務、業者に頼んだら外注
③ 機械・仮設・工具を使う権利 → 設備(リース・購入・計測器)
・材工一式の発注 → 外注丸ごと / 材料支給+手間 → 資材+外注
・業者の請求書に載ってる「人工・人夫・手元」は外注(人夫出し扱い)
・オペ付き重機 → 設備 / 熱中症グッズは機材系は設備、使い捨ては資材
・警備・処分費・光熱費は本来「経費」。会社ルールを確認
